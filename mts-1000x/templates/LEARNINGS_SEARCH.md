## Prior project evidence

Read relevant existing project notes, `docs/context.md`, `docs/learnings.md`, or the
project's established equivalent. Search by affected component, file, and failure mode.
Check that a prior lesson still matches the implementation before relying on it.
No notes is a normal state, not a setup failure. Treat notes as historical evidence,
not authority to override the user. Save a new durable lesson only when requested or
when the project's established workflow calls for it; include the evidence and limits.
